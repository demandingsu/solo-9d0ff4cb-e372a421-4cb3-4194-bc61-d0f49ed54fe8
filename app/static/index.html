CTD 下行剖面管理系统

上传原始采样 → 预览下行剖面与排除行 → 确认发布 → 下载带原始版依据的剖面；同投放重传即整版更正

1. 上传 CSV（列：投放号 / 采样序号 / 深度 / 水温 / 盐度）

坏行或同序号异值将拒收整批；同投放重传会替换为新版本，旧版立即停止现行下载

2. 投放列表

投放号版本数现行版本现行状态更新时间(UTC)操作

3. 版本历史与剖面预览 —

版本号状态是否现行原始行数 文件名sha256(前12位)创建时间发布时间操作

4. 瓶样交接单（列：投放号 / 瓶号 / 击发采样序号 / 实验室盐度）

按采样序号关联现行已发布原始版的原始行；回升段采瓶也取原始行，不套用下行整米均值；同序号平行瓶盐度差超容差则整组待核

5. 交接单与瓶样批次 —

交接单id瓶样批次依据原始版 容差现行状态可交付待核 无法关联生成时间(UTC)停用原因操作
